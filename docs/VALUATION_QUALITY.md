# 估值质量与数据口径

## 持仓识别

优先使用披露中的交易所链接，其次是明确的交易所后缀、已验证 ISIN 和代码与公司名共同匹配的映射。四位代码本身不能证明是日本或台湾上市；无法确定的市场和币种保留为空，不默认人民币，也不拿 ADR 代替普通股。

映射在 `backend/holding_identity.py` 维护。worker 启动时只修复数据库中没有行情映射的记录，不更改持仓权重、报告期或已有明确映射。映射变化会更新披露签名，并使旧估值快照失效。

已核查的发行人资料包括 [村田](https://corporate.murata.com/ja-jp/ir/faqs)、[古河电气](https://www.furukawaelectric.com/en/ir/)、[住友电工](https://sumitomoelectric.com/ir/faq)、[三井金属](https://www.mitsui-kinzoku.com/toushi/stock_info/kihon/)、[东京电子](https://www.tel.com/ir/faq/)、[藤仓](https://www.fujikura.co.jp/en/ir/faq/)；新增映射仍须核对发行人、交易所和具体股份类别。

日本、韩国复用现有 Naver 行情与日线接口。接口可用不代表没有交易所延时；台湾和欧洲尚未可靠映射的持仓仍不参与直接贡献，不能认为已达到完整覆盖。

## 价格与收益

- `stock_daily_history.close` 保留原价，`stock_price_basis` 记录逐期口径、来源与抓取时间。
- 腾讯港股日线明确请求 `day` 原价，不使用 `qfqday` 覆盖已有原价。旧港股历史无法区分原价和前复权价，估值使用前需由 worker 重新抓取。
- A 股个股复用已存在的后复权因子维护。有可靠因子时，将送转、拆并股、现金分红计入收益；当前没有完整的全球企业行为数据库。
- 未验证的明显价格断点不直接当作跌幅，也不人为改成零收益。该持仓暂不参与直接估算，由原有剩余仓位规则处理。这个防护可能排除真实的大幅波动，也不能识别全部小额分红。
- 比较前后两天时采用共同有数据的持仓集合，避免覆盖率变化本身产生虚假日收益。

持仓贡献仍为 `权重 × [(1 + 股票收益) × (1 + 汇率收益) - 1]`；缺失股票不意味着贡献为零。显示的股价保持原价，收益和贡献可包含已验证企业行为修正。

## 快照一致性

卡片快照去掉持仓明细以减小响应，但保留 `snapshotId`。展开时读取对应快照，而不是重新计算。每只基金保留最近三份详情，超出后显示等待同步，不拼接不同批次。

官方净值的日期或数值任一变化，旧估值不再作为当前卡片结果。已确认的预测观察记录不再被后续重算覆盖。模型和输入签名隔离新旧价格口径，不混用拟合样本。

## 内部质量观察

worker 每周生成最近 90 日观察报告，也可只读运行：

```bash
.venv/bin/python -m backend.valuation_quality --database /path/to/fund_valuation.db --days 90
```

报告按基金、模型和输入签名分组，包含样本数、平均绝对误差 MAE、带正负号的平均偏差、披露持仓中缺行情的平均权重。误差单位为百分点，不是净值金额。没有采集缺失权重的旧记录显示未知，而非零。

只纳入已完成且有官方涨跌幅的观察，要求比较日与官方前一净值日期一致；同日待公布与实时参考不重复计样本。样本不足时仅观察。达到 30 个样本仍须通过原有按时间划分的样本外验证，不能直接启用拟合。

此报告不是可交易回测，也不根据历史拟合自动重写模型。受保护诊断接口中的 `valuationQuality` 返回最近报告；不增加公开回测页面或外层可信度标记。
