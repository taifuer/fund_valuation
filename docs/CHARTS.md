# 图表基础规范

- `ChartBase.module.css` 统一白底绘图区、11px 坐标文字、12px 读数文字、18px 重点数值、2.5px 线宽、网格、选中点和十字线。图表工具控件复用 `AnalysisBase.module.css`。
- 历史和公司整页图使用296px高度；基金和股票详情保留适合弹窗的紧凑高度及浮动提示，涨跌线色不变。
- 整页图采用固定读数栏、整幅绘图区选择最近有效点。手机允许纵向滚动并支持点按；键盘仅一个焦点入口，方向键选择，Home/End跳至两端。公司图按点密度减少圆点，不删除披露数据。
- `chartLayout.ts` 复用文字宽度、刻度避让、坐标变换和最近点查找；线性坐标采用规整刻度并预留上下空间，对数坐标保留等比例距离。价格完整显示，财报金额保留其币种与量级，不变更数据或收益计算。
- `companyPlotSeries` 按实际披露截止日期定位。缺失指标或缺期时断线，年度及半年披露按各自频率判断；保留同比零线、员工口径和重大披露标记。不填补不存在的财报数据。
- 移动端历史区间保留原生选择器，关闭触摸高亮并仅在精细鼠标设备应用悬停边框。指针选择不保留焦点描边、不主动失焦；键盘导航和重新Tab进入仍显示焦点框。历史指标用右上角 `*` 关联底部分行说明，回撤的月末频率不重复在标题中；回撤使用中性颜色，沿用表格内部横向滚动。

变更后检查桌面与320/390px手机宽度、坐标标签、长数字、缺失值、负值、恒定序列、同比零线、对数比例、触控滚动及键盘选点。
