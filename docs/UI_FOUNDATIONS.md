# UI 基础约定

## 共用基础

- `src/index.css`：字体、语义颜色、页面宽度/留白、控件高度和焦点颜色。
- `PageBase.module.css` / `PageHeading`：页面容器、标题和说明。
- `AnalysisBase.module.css`：筛选、分段选择、下拉框、输入框、操作按钮和分析表格。
- `ChartBase.module.css`：图表轴线、网格、走势线、选点和键盘焦点。

页面最大宽度为 1040px；720px 及以下左右留白为 12px，其余为 16px。
常规筛选和下拉框外部高度为桌面 32px、移动端 40px；分段按钮计入外框的边框、内边距后保持同高。
管理弹窗的表单控件在桌面也保持 40px，方便输入令牌和基金代码。

## 交互层级

- 一级页面导航保留胶囊样式；页面内视图导航保留下划线，不能与普通筛选混为一类。
- 地区、分类、时间、基金详情页签采用深底白字选中态。
- 公司/长期标的列表采用浅底边框选中态，保持密集列表的可读性。
- 表格排序、行内标记、关闭图标和行情数字保留用途所需的尺寸，不强制全部等大。
- 悬停效果只对支持悬停的精细指针生效，不能覆盖选中态；键盘焦点必须可见。
- 原生时间选择框沿用触摸焦点标记：触摸不残留高亮，键盘操作恢复焦点轮廓。

## 修改与验证

CSS Modules 的 `composes` 不保证基础类与局部类的加载顺序。
需要不同的内边距或最小宽度时，优先使用 `--segment-min-width`、`--segment-padding`、
`--action-font-size`、`--action-padding`、`--input-font-size`；布局约束使用明确的父级选择器，
不要靠同优先级规则的先后顺序覆盖。

改动公共样式后运行 `npm test`、`npm run build` 和 Playwright 回归。
`control-consistency.spec.ts` 覆盖触摸/悬停选中态、键盘焦点、懒加载切页、
320–1280px 的控件尺寸与留白，以及基金详情、图表弹窗、财报日历和诊断表单。
